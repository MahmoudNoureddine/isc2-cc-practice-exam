# ISC2 Certified in Cybersecurity (CC) — Scenario-Based Practice Exam
 
A free, open-source set of **200 scenario-based practice questions** for the [ISC2 Certified in Cybersecurity (CC)](https://www.isc2.org/certifications/cc) exam — built to match the style, difficulty, and domain weighting of the official exam. Every question includes the correct answer **and a short justification**, so you understand *why*, not just *what*.
 
Made for anyone self-studying for the CC exam: career switchers, IT students, and entry-level candidates preparing for their first cybersecurity certification.
 
## What's inside
- **200 questions**, all scenario/situational style (matches how ISC2 actually phrases exam questions)
- Organized into the **5 official CC domains**, weighted the same as the real exam:

| Domain | Questions | Weight |
|---|---|---|
| 1. Security Principles | 52 | 26% |
| 2. Business Continuity, Disaster Recovery & Incident Response Concepts | 20 | 10% |
| 3. Access Control Concepts | 44 | 22% |
| 4. Network Security | 48 | 24% |
| 5. Security Operations | 36 | 18% |

## How to use this
 
- Read the study notes for a domain first to build the mental model, then test yourself with that domain's questions in the practice exam
- Cover the answers and self-test, then compare against the justifications
- Use the "Fast-Recall Summary" at the bottom of each notes file as a final review pass before exam day
- Import into a spaced-repetition tool if you want daily drilling
